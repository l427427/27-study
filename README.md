# AI 学习导师 — 本地学习工作区

> 这是 Hermes AI 学习导师系统的本地持久化数据目录。
> 导师人格和教学逻辑在 Hermes Profile 和 `ai-learning-mentor` Skill 中，
> 这里只保存学习项目持续变化的状态、记录、错题和总结。

## 目录结构

```
AI-Study/
├── README.md                        ← 本文件
├── 状态数据/
│   ├── system-state.json            ← 系统状态机（当前阶段、今日会话）
│   ├── roadmap.json                 ← Roadmap 唯一结构化真相源
│   ├── mastery.json                 ← 知识点掌握度矩阵
│   ├── roadmap-changelog.md         ← Roadmap 调整原因与历史
│   └── dashboard-data.json          ← 可由核心数据重新生成的展示数据
├── 每日记录/
│   └── YYYY-MM-DD.md                ← 当天教学、练习、批改、打卡与实际用时
├── 错题本/
│   └── 按知识主题归档.md
├── 总结/
│   ├── 每日/YYYY-MM-DD.md
│   ├── 每周/YYYY-Www.md
│   └── 阶段/
├── 资料库/
│   ├── 用户提供/
│   └── 来源索引.md
└── Dashboard/                        ← 本地可视化网站
    └── （前端文件）
```

## 使用方式

1. **学习**：在 Hermes 中说「今天学什么」「继续昨天」即可进入教学
2. **查看进度**：启动 Dashboard 本地网站查看可视化面板
3. **暂停**：说「暂停学习」暂停当前周期
4. **重置**：说「重新规划」经确认后重置学习档案
5. **备份**：直接复制整个 `AI-Study/` 目录

## 数据安全

- 所有数据默认保存在本地
- JSON 文件采用原子写入（先写临时文件再替换）
- 关键状态更新前自动备份
- 任何外发操作都有明确边界
