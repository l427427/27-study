## 五、Roadmap 与系统侧调整（含责任项）

1. **roadmap 内容：第 5 周不动**（phase-3 t113–t205 保守基线；无任何用户实报）。⏳ 注意：phase-3 只剩 10 天（9/30 收口），若到 9/30 仍无用户输入，phase-4（10/1 起）**不能自作主张**——按 Conservative 续排，并在提醒里以**问句**请用户拍板节奏。
2. **【新修 · 备份链静默故障】** 3 小时一次的「自动备份到GitHub+服务器」job **一直报 `ok`，但自 9/17 12:23 起 3 天零提交**。根因：`sync-study.sh` 里提交消息没加引号 —— `git commit -m 自动备份 2026-08-03 17:28` 被 git 当成「消息 + 两个路径」，直接 `fatal: pathspec '2026-08-03' did not match`（已用 `--dry-run` 复现）→ 提交失败被 `>/dev/null 2>&1` 吞掉 → 本地无新提交 → `git push` 变成 "Everything up-to-date" → job 退出 0 全绿。**修复**：消息整体加引号 + 用 `$(date '+%Y-%m-%d %H:%M')` 动态取（不再写死 8/3），且 commit 失败改为 `exit 1` 让 job 变红。两处副本均已改（profile + global），并新增「GitHub 最新提交时间」为每周固定检查项。
3. **探测链断点修复（H20）**：9/18、9/19 连续两天**无探测行**（其余 5 天有）。根因：每日 09:00 job 只挂了 `ai-learning-mentor`，prompt 里也没写探测步骤——「每日固定动作」全靠 LLM 自觉，一忙就漏。**修复**：① `hermes cron edit 0d34337730f8 --add-skill ai-mentor-review-ops` 把运维手册挂到开课 job；② 新增一键包装器 `scripts/ilink-probe-log.py`（跑探测 + **自动**把结果追加进 `ilink-diag.log`，LLM 不需要再编辑文件），并用 stub harness `ilink-probe-log-selftest.py` 覆盖「未恢复 / 通道恢复」两分支（12 项断言全 PASS，零网络流量）。
4. **system-state 日期推进**：9/17 → **9/20**（第 48 → **51** 天）；`today_session.date` = 2026-09-20，`actual_minutes_available` = 390。
5. dashboard 口径复核：`overdue = 148`（date<9/20 且未完成且**排除 24 项 archived**），与 roadmap 独立重数一致；`completed = 0` 未伪造。
